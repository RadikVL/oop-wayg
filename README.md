# Python OOP — лабораторные работы

Учебный репозиторий по объектно-ориентированному программированию на Python.

**Вариант предметной области:** №4 — Банковская система.

## Структура

```
.
├── README.md
├── src/
│   ├── lib/                       # общий код (зарезервировано под спецификацию)
│   ├── lab01/                     # ЛР-1 — класс и инкапсуляция
│   │   ├── model.py, validate.py, demo.py, README.md
│   ├── lab02/                     # ЛР-2 — коллекция объектов
│   │   ├── model.py, collection.py, demo.py, README.md
│   ├── lab03/                     # ЛР-3 — наследование
│   │   ├── base.py, models.py, collection.py, demo.py, README.md
│   ├── lab04/                     # ЛР-4 — интерфейсы (ABC)
│   │   ├── interfaces.py, models.py, collection.py, demo.py, README.md
│   ├── lab05/                     # ЛР-5 — стратегии и функции высшего порядка
│   │   ├── model.py, strategies.py, collection.py, demo.py, README.md
│   └── lab06/                     # ЛР-6 — Generics и Protocol
│       ├── model.py, container.py, demo.py, README.md
└── images/
    ├── lab01/ ... lab06/          # скриншоты к отчётам
```

## Список лабораторных

| № | Тема                                       | Каталог       |
| - | ------------------------------------------ | ------------- |
| 1 | Класс и инкапсуляция                       | `src/lab01/`  |
| 2 | Коллекция объектов                         | `src/lab02/`  |
| 3 | Наследование и иерархия классов            | `src/lab03/`  |
| 4 | Интерфейсы и абстрактные классы (ABC)      | `src/lab04/`  |
| 5 | Функции как аргументы. Паттерн «Стратегия» | `src/lab05/`  |
| 6 | Generics и `typing.Protocol`               | `src/lab06/`  |

Каждая лаба — самодостаточна: со своими копиями `model.py` и т.п.,
никаких хитрых импортов между папками. Можно запустить любую,
не трогая остальные.

## Сквозная предметная область

Во всех лабах — банковские счета:

- `BankAccount` — базовый счёт (ЛР-1+).
- `CreditAccount` — кредитный, наследник `BankAccount` (ЛР-3+).
- `DepositAccount` — вклад с замороженным сроком (ЛР-3+).
- `AccountBook` — контейнер для счетов (ЛР-2+), от лабы к лабе обрастает
  методами (фильтры по типу, через интерфейсы, стратегии, Generic-версия).
